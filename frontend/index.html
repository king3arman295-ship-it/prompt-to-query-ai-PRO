How to use this product

  1. Add a database using the sidebar (+ Add Database).
  2. Click Save & Scan — the system reads all tables, columns, PKs and FKs.
  3. Select the database, then ask questions in plain English.
  4. Edit the generated SQL if needed, then download results as CSV / Excel / SQL.
